Process

How It Works

Our detection pipeline follows a rigorous 5-step process from text input to final prediction.

1. Submit Text

Paste a political article, speech, or social media post for analysis.

2. Preprocessing

Text is cleaned, tokenized, and stopwords are removed for analysis.

3. Feature Extraction

TF-IDF vectorizer converts text into numerical feature vectors.

4. Classification

ML models classify the text using trained classifiers.

5. Prediction

Results with confidence scores and probability breakdowns.
